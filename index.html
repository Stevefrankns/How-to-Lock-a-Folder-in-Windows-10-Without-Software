How to Lock a Folder in Windows 10 Without Software

If you want to lock a folder in Windows 10 without installing software, Windows gives you several built-in protections—but they do different jobs. You can use EFS on supported editions to encrypt files, separate Windows accounts and NTFS permissions to keep other standard users out, or BitLocker/Device Encryption to protect a drive if the PC is lost or stolen. Windows 10 does not include a built-in feature that adds an independent password prompt to one ordinary folder.

Quick answer

For built-in protection on Windows 10 Pro, Enterprise, or Education: use Encrypting File System (EFS) from Properties → Advanced → Encrypt contents to secure data. EFS is tied to your Windows account, not a separate folder password. Windows 10 Home does not include EFS. BitLocker protects drives, not individual folders. If you specifically need a separate password for one folder, use a reputable encrypted container/archive or dedicated vault instead of a hidden-folder or batch-file trick.

What “locking a folder” actually means in Windows 10

Searches for “how to lock a folder in Windows 10,” “password protect folder Windows 10,” and “how to add a password to a folder” often describe the same goal but different security needs. Before choosing a method, separate four concepts:

Hide

Changes visibility in File Explorer. It is easy to reverse and provides no encryption.

Restrict access

Uses Windows accounts and NTFS permissions to keep standard users out. Administrators can change permissions.

Encrypt

Transforms the data cryptographically. EFS can encrypt files in supported editions; BitLocker encrypts drives.

Separate password

Requires an encrypted archive/container or security tool that asks for a password independently of the Windows sign-in.

Method 1 · Built in

Encrypt a folder with EFS in Windows 10 Pro, Enterprise, or Education

Microsoft’s Encrypting File System (EFS) encrypts files on NTFS volumes and ties decryption to the Windows user’s encryption key. It is useful when multiple people have separate Windows accounts and you want the files unreadable to other users. It is not available in Windows 10 Home, and it does not create a separate password prompt when the owner opens the folder.

  1. Right-click the folder and select Properties.
  2. On the General tab, select Advanced.
  3. Select Encrypt contents to secure data, then choose OK.
  4. Select Apply and confirm how broadly you want the encryption applied.
Important limitation

EFS follows the Windows account. If the same account is already signed in, the encrypted files open normally. That is why EFS is excellent for account-based protection but does not satisfy the search intent “ask me for another password every time I open this folder.” Protect your Windows sign-in and keep a secure backup strategy for encryption keys/certificates before relying on EFS for irreplaceable data.

Official reference: Microsoft — How to encrypt a file or folder.

Method 2 · Shared PC

Use separate Windows accounts and folder permissions

If your real problem is “another person who uses this PC should not browse my files,” the simplest model is often separate Windows accounts. Each person signs in with their own password/PIN and gets a separate profile. NTFS permissions can then restrict which users can read a folder.

This is access control, not encryption. A local administrator can generally take ownership or change permissions, so do not treat permissions alone as protection against an administrator or an attacker with offline disk access.

Official reference: Microsoft — Manage user accounts in Windows.

Method 3 · Device loss

Use BitLocker or Device Encryption when the threat is a stolen drive

BitLocker is designed for drive-level encryption. It protects data if someone removes the disk or tries to read it offline, but it does not put a password on one ordinary folder. Device Encryption provides a simpler drive-encryption experience on supported hardware and editions.

Use BitLocker/Device Encryption for the laptop or storage device, and use EFS or a separate encrypted container if one folder needs a different access boundary.

Official references: Microsoft — BitLocker overview and Device Encryption in Windows.

Avoid false security

Hidden folders and batch scripts are not encryption

Folder-hiding tricks, renamed “Control Panel” folders, and common CMD/batch-file scripts can deter casual browsing, but the files are still present and the script may expose its password in plain text. Do not use those methods for tax records, identity documents, work secrets, or anything that would matter if copied.

Before you lock anything

Recovery and backup rules that prevent permanent data loss

Keep an independent backup

Encryption is not a backup. Keep another protected copy of irreplaceable files before changing encryption or permissions.

Protect recovery material

BitLocker relies on recovery keys. EFS relies on user certificates/keys. Losing recovery material can turn a routine reinstall into a data-loss event.

Test recovery

Before moving all important files, encrypt a test folder, sign out/restart as appropriate, and verify both normal access and the recovery process.

Do not uninstall blindly

If third-party encryption is used, follow the vendor’s documented unlock/export procedure before uninstalling or resetting Windows.

Bottom line

Choose the lock based on who you are protecting the folder from

For another standard Windows user, separate accounts and EFS can be enough. For a stolen PC or drive, use BitLocker or Device Encryption. For a true password on one folder, use a properly encrypted container or vault. And for Windows 10 in 2026, treat operating-system support itself as part of the security plan.
